# The Meridian Wire — Saturday 21 November 2026 in one picture

A single 1024x1024 front page summing up Saturday 21 November 2026: 38 stories
from 7 regions — missiles landing in Poland, COP31 slipping into overtime,
Wall Street's fall into correction, the Kryvyi Rih strike, Denmark's exposed
plot and 33 more.

Every story names its sources on the page, per-card source tags sit on each
illustrated strip, and each strip carries the story's own data label.
The map is drawn from real country polygons, with numbered pins for the 13
pictured stories and dots for the briefs; a DATE CHECK box names the
Friday stories deliberately left out.

All illustrations are original drawings — flat shapes composed by draw.py,
a deterministic Pillow program (stdlib + PIL only, no network, no randomness).
main.py copies the finished entry.png into the output directory.
